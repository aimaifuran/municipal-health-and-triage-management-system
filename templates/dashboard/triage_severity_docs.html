Reference for nurses and doctors. Severity is automatic — there is no manual Critical/Stable selector. Source: docs/TRIAGE_SEVERITY_EVALUATION.md

1. Overview

StepAction
1Nurse submits vitals + symptoms
2System runs clinical triage engine
3Assigns tier (RED / ORANGE / YELLOW / GREEN)
4Maps to Critical, Moderate, or Stable + priority score
5Queue ordered by priority; critical → Escalated

2. Severity levels (in the app)

6. Priority score

ScoreInterpretation
80–100Critical emergency
55–79High priority
30–54Moderate
0–29Low / stable

7. Safety principles

  • When uncertain between two tiers, the system chooses higher acuity.
  • Stroke, heart attack, and sepsis patterns are not downgraded because vitals look near-normal.
  • Output supports triage only — not a definitive diagnosis.
